# SmartCare 智能托管助手 (MVP v1.0 Demo)

这是一个基于 HTML/CSS/JS 的纯前端交互演示项目，展示了 **SmartCare 智能托管助手** 的核心功能流程。

## 📱 演示入口

🚀 **[点击这里体验 Demo](index.html)**  
*(部署后直接访问项目根域名即可，例如 `https://smart-care-demo.vercel.app/`)*

## ✨ 核心功能

### 👨‍🏫 老师端
*   **首页**: 班级概览与统计
*   **考勤工作台**: 两段式考勤（校门接送 -> 班级入托）、极速点名
*   **连拍相机**: 作业极速归档、双通道入口 ("今日全对" / "提交错题")
*   **学生档案**: 个人成长记录、一键联系家长

### 👨‍👩‍👧 家长端
*   **今日动态**: 查看孩子接送状态、作业报告
*   **历史档案**: 查看历史错题集与老师评价



## ⚠️ 注意事项
*   本 Demo 为 **纯前端演示**，数据均为本地 Mock 数据，刷新页面后会重置。
*   并没有连接真实的后端数据库。

## 📝 版本更新日志 (Changelog)

### v1.0.9 (2026-02-22) - 核心体验与功能对齐 PRD 1.0

本次更新全面落实了 1.0 PRD 的各项核心交互与功能闭环，相比早期 Demo 有以下重大演进：

#### 🌟 核心业务流程升级
*   **[Tab 1] 点名考勤工作台优化**
    *   重构底层 HTML DOM 结构，修复乱码与标签嵌套问题。精简 Tab 命名为“点名”、“作业”、“错题”。
    *   **智能状态球迭代**：完善单向演进逻辑（待接 -> 途中 -> 入班）。
    *   **左滑交互防误触（Swipe Interaction）**：实现左滑丝滑呼出「撤销」与「请假」菜单，全局拦截 click 穿透，彻底解决向左滑动误触发学生详情跳转的 Bug，确保校门口接送的高并发考勤零失误。
*   **[Tab 2] 作业建档区（无感保存版）**
    *   移除全局保存按钮，实现**操作即保存（极简录入+无感保存）**。
    *   上线跨校、跨班级多维度数据隔离：确保作业清单与原始图片数据严格按「学校+班级」标签加载，杜绝数据串台。
*   **[Tab 3] 极速连拍与错题反馈**
    *   创新**相机双通道入口**：引入全新的「🎉 今日全对」无图捷径入口（金色主题）以及常规的拍摄「提交」错图入口（绿色主题）。
    *   **全功能归档反馈弹窗**：弹窗内支持轻量化标签评价选点（如：书写工整、速度快等）与留言免打字体验。支持智能生成对应图文或纯文本寄语的学习报告卡。

#### 👨‍👩‍👧 家长端与学生档案双端联动
*   **双端 UI 与逻辑闭环**：实现老师端 (`student_profile.html`) 和家长端 (`parent-daily.html`) 视图模块的 100% 像素级对齐同步。
*   **历史成长档案（五层架构大组件）**：为学生档案引入五层维度（考勤-作业-表现-错图-寄语）的组件级渲染展示。支持错图横滑预览及大图模态窗，且“今日全对”享有“Perfect Day”专属金色光斑卡片与角标展示。
*   **页面重力滚动与流式通知锚点联动**：在家长今日动态页引入点击头部通知卡片，平滑下滚（ScrollIntoView）并高亮微弹定位落点至具体历史档案的功能。

#### 🔒 账号体系与体验升级
*   **统一鉴权登录页**：完成重构版的一键授权登录，分离老师和家长双身份入口。新增微信登录与获取手机号的体验流以及资料修改编辑模态弹窗。
*   各类细节微调，优化了核心页面的视口弹性和滚动阻尼。
