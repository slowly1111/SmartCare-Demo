# 产品需求文档：智能托管助手 (SmartCare) - MVP v1.0

## 1. 综述 (Overview)

### 1.1 项目背景与核心问题

传统托管机构老师在放学高峰期面临"接送安全"与"作业反馈"的双重压力。目前主要依赖微信群发消息，存在效率低（一张张发图）、信息杂（家长爬楼难）、隐患大（接送状态不透明）等痛点。

本项目旨在通过 **小程序 + 云开发** 技术，用"极速连拍"和"两段式考勤"降维打击现有流程，为老师提效，给家长确定性。

### 1.2 核心业务流程 / 用户旅程地图

1. **阶段一：安全接送 / [Tab 1: 点名]** - 校门口极速点名（灰->黄），进班后一键入班（黄->绿），老师确认今日出勤名单，确保接送闭环。
2. **阶段二：作业录入 / [Tab 2: 作业]** - 下午暂存建档。老师按“学校+班级”二级筛选，利用“简录+原图”建立今日作业清单并静默保存。
3. **阶段三：错题反馈 / [Tab 3: 错题]** - 晚上质检与发报。老师调出下午清单无脑勾选，针对错题进行连拍，云端生成 PDF 报告并推送家长。

### 2.4 [Tab 1] 点名与状态管理

#### **US-01: 老师工作台与状态管理**

* **价值陈述**:
  * **作为** 托管老师
  * **我希望** 在一个页面能一眼看到班级所有人的实时状态，并能通过简单的点击完成状态变更
  * **以便于** 在嘈杂的校门口和忙碌的教室里快速完成考勤，不出安全事故

* **业务规则与逻辑**:

1. **页面布局 (参照已确认 UI)**:
   * **顶部统计筛选条**: 必须包含 **[全部] [待接] [途中] [入班] [请假]** 五个 Tab
   * **学生卡片**: 展示头像、姓名、作业归档标、**智能状态球**
   * **底部操作栏**: 左侧 [📷 拍作业]，右侧 [✅ 一键全部入班]

2. **智能状态球逻辑 (核心)**:
   * **点击交互**: 状态单向演进逻辑 `⚪ 待接 (0)` -> `🟡 途中 (1)` -> `🟢 入班 (2)`。当达到“入班”状态后，点击事件将被锁定（防止误触导致的签退），必须使用左滑菜单进行撤销操作。
   * **左滑交互 (新特性)**: 在学生卡片上向左滑动，会无缝展开两个操作菜单：
     * `[撤销]` (灰色)：将状态重置为 `⚪ 待接 (0)`
     * `[请假]` (红色)：将状态置为 `⛔ 请假 (3)`
   * **防误触机制**: 引入精准的手势识别（横向位移超 5px 即判定为滑动意图）。这不仅支持从展开状态直接向右反滑闭合，而且滑动结束松手时**100% 拦截 click 穿透**，绝不会误触发进入学生详情页的逻辑。

3. **学生详情页入口**:
   * 点击学生卡片左侧的学生信息区（且没有发生滑动干扰），即可进入对应学生的详情页 `student_profile.html`

4. **一键全部入班**:
   * 批量更新状态为"途中"的学生为"入班"

* **验收标准**:
  * **场景1: 校门口接人 & 防误退**
    * GIVEN 学生"谭圣涵"当前是"待接"
    * WHEN 老师连续点击两次他的状态球
    * THEN 状态瞬间从待接变为"途中"再变为"入班"，且第三次点击不再起效
  * **场景2: 请假操作**
    * GIVEN 老师收到请假通知
    * WHEN 老师对某学生向左滑动并点击"请假"
    * THEN 卡片自动收合，状态显示为"请假"
  * **场景3: 去拍作业**
    * GIVEN 老师点击学生去拍照，随后拍完或者想退出
    * WHEN 老师点击相机页左上角的“返回”
    * THEN 页面稳定且精准地跳转回 `check-in.html` 的**错题反馈 (Tab 3)**，而非默认的点名页

### 2.5 [Tab 2] 作业 (下午建档区 - 无感保存版)

**核心逻辑**：极简录入 + 无感自动保存 + 按学校/班级数据隔离。老师所见即所得，无需点击任何全局级别的"保存"按钮。

```text
|                                                 |

|  [✅ 全部班级 ]  [ 1.1班 ]  [ 1.5班 ]             |
|                                                 |
| 👥 包含学生: 谭圣涵, 马震凯 (防呆小字提示)          |
| ----------------------------------------------- |
|                                                 |
| 📝 3. 快速录入区                                  |
|  【科目】 [✅ 语文] [ 数学] [ 英语] [(+)自定义]     |
|                                                 |
|  【输入】 [ 请输入作业要求...                 ] [🚀]|
|                                                 |
| ----------------------------------------------- |
|                                                 |
| 📋 今日清单 (育才小学 - 全部班级)                   |
|                                                 |
|  1. [语文] 预习第20课                      [删]   |
|  2. [数学] 一张卷子，基本都上交了            [删]   |
|                                                 |
| ----------------------------------------------- |
|                                                 |
| 📎 附件原图 (最多9张)                             |
|  [ 📷 拍黑板/截图 ]  [ 图片缩略图 ]                 |
|                                                 |
+-------------------------------------------------+
```

**【业务规则与后台逻辑】**

1. **组合维度数据隔离 (核心)**：
   * 所有录入的"今日清单"和"附件原图"，在存储和展示时均严格绑定当前的 **[学校 + 班级]** 组合。
   * **前端表现**：当老师切换上方的学校或班级时，下方的"今日清单"和"附件原图"区域必须立刻清空或加载对应组合的历史数据，杜绝数据串台。

2. **操作即保存 (无感保存)**：
   * 页面**完全移除**底部全局的「保存/发布」按钮。
   * 点击🚀(或回车)添加作业、点击[删]移除作业、上传/删除附件图片等任何动作，都必须**立刻触发**后端接口同步写入 `assignments` 表，并在前端给出轻量级的高频交互反馈 (如 Toast "已自动保存")。

3. **快捷交互优化**：
   * **科目记忆**：点击横排科目标签进行单选。添加一条作业后，当前选中的科目**不重置**，方便老师连续录入同一科目的多项作业。
   * **自定义科目**：点击 `(+)` 弹出悬浮气泡，允许输入如"科学"、"道法"等临时科目，输入后作为新标签追加到末尾并自动选中。

4. **防呆名单拼装**：根据选中的学校和班级，过滤出对应的学生 `name` 数组，作为小字展示给老师核对。

### 2.6 [Tab 3] 极速连拍与错题

#### **US-02: 极速连拍与作业归档**

* **价值陈述**:
  * **作为** 托管老师
  * **我希望** 能连续拍摄多张错题而不被打断，拍完自动归档，并能快速给家长反馈
  * **以便于** 节省在相册里选图、发微信的时间，同时让家长感受到老师的关注

#### **2.5.1 相机页双通道入口设计 (核心创新)**

* **设计理念**: **入口分流，出口统一** —— 无论有没有错题，老师都能顺畅完成反馈

* **页面布局线框图**:
```text
+-------------------------------------------+
|  ←          为 谭圣涵 拍摄                 |
+-------------------------------------------+
|                                           |
|               [ 相机取景框 ]               |
|                                           |
+-------------------------------------------+
|        [ 数学 ]  [ 语文 ]  [ 英语 ]         |
+-------------------------------------------+
| [ 缩略图预览条: (空) 或 (照片1, 照片2...) ] |
+-------------------------------------------+
|                                           |
|  [🎉 今日全对]     (○)      [ 提交 (0) ]   |
|    金色入口       快门键      绿色入口     |
|                                           |
+-------------------------------------------+
```

* **业务规则与逻辑**:

1. **左侧金色按钮「🎉 今日全对」**:
   * **功能**: 无需拍照，直接打开归档弹窗
   * **场景**: 学生今天作业全对，无错题需要归档
   * **弹窗状态**: 标题为"🎉 确认全对归档"，金色主题

2. **中间快门按钮**:
   * **功能**: 拍摄错题照片，飞入底部预览条
   * **交互**: 点击后闪光动画 + 震动反馈

3. **右侧黑色/绿色按钮「完成拍摄 (n)」**:
   * **功能**: 必须先拍照 (n>0) 才能点击，点击后不再直接弹出评价反馈弹窗，而是**将照片缓存至暂存区（草稿池）**并返回工作台。
   * **交互**: 弹窗提示"已保存 n 张草稿，稍后可补充评语发送"；列表对应学生状态变更为"� 已存草稿"，老师可在闲暇时统一点击「✏️ 完善并发送」进行集中反馈评价。

#### **2.5.2 学习反馈模块 (归档弹窗内)**

* **设计理念**: **标签为主 (80%) + 文字为辅 (20%)** —— 让老师1秒完成评价，避免"必填小作文"

* **弹窗布局线框图**:
```text
+-------------------------------------------+
|  📦 确认错题归档  /  🎉 确认全对归档        |
+-------------------------------------------+
|                                           |
| 【1. 今日作业核对】 (系统拉取下午建档清单) |
|  [✅完成] [❌未完]  语文 - 预习第20课      |
|  [✅完成] [❌未完]  数学 - 一张卷子...     |
|  *(交互：二选一，默认选中✅完成，零打字)*  |
|                                           |
| 【2. 综合表现】 (点选)                     |
|  [👍 书写工整] [⚡ 速度快] [🧠 思路清晰]    |
|  [🐢 有点拖拉] [💪 需要鼓励]               |
|                                           |
|  💬 老师留言 (选填)                        |
|  ┌─────────────────────────────────────┐ |
|  │ 例如：今天背诵课文非常流利...         │ |
|  └─────────────────────────────────────┘ |
|                                           |
|  📄 已拍摄 3 张数学作业 / ✨ 将生成表扬卡   |
|                                           |
|     [ ✅ 确认发送给家长 ]                  |
+-------------------------------------------+
```

* **字段定义**:
  | 字段 | 类型 | 必填 | 说明 |
  |------|------|------|------|
  | 表现标签 | multi-select | ❌ | 预设5个标签，支持多选 |
  | 老师留言 | textarea | ❌ | 最多200字，用于个性化沟通 |

  | 特性 | 常规拍摄归档 | 全对捷径归档 |
  |------|--------------|--------------|
  | 入口 | 错题列表页 "完善并发送" 按钮 | 相机页左侧 "今日全对" 按钮或列表页 |
  | 前置条件 | 已有暂存的草稿照片 | 无需拍照 |
  | 弹窗主题色 | 🟢 绿色 | 🟡 金色 |
  | 文件提示 | "已选择 X 张错题，准备生成 PDF" | "✨ 将生成表扬卡" |
  | 默认标签 | 无 | 自动选中"书写工整" |

#### **2.5.3 防呆校验与交互进阶 (1.0 补充方案)**

* **核心挑战**: 在试运行中发现了四个真实体验痛点（如错题科目混用、假人空数据也能拉起弹窗等），在 1.0 代码层已得到对应解决：
  1. **跨表前置阻断**: 列表中（Tab 3）只能看到 **状态 = 2（入班）** 的同学。那些请假和未入班的学生会被代码底层静默剥离，彻底杜绝老师手误错发报告的尴尬。
  2. **多科连拍强隔离**: 照片回传结构由原本单纯的图片地址数组 `[url]` 变成了高维对象数组 `[{url, subject}]`。这意味着弹窗中可以看到每张错图带有的专属小黑牌角标记号。
  3. **空照片允许下钻**: 若学生没有错图，允许直接在弹窗内选中 "今日全对" / "表现优异" / "速度快" 并生成**纯文本形式的赞美报告**，底部说明自动回退为“未抓拍错题，将生成纯评价报告”。
  4. **无感跨页回填**: 修改历史报告时，标签状态与评语内容可严丝合缝地回写进弹窗视图。

* **页面结构 (三段式)**:
  1. **Header**: 紫色渐变背景，学生头像、姓名、班级
  2. **Today Section (流式播报区)**: 今日事件时间轴 (注重时效性，极简纯白卡片)
  3. **History Section (深度归档区)**: 历史成长档案 (支持按月筛选，承载五层架构图文报告)

* **今日动态 (Today Section) 交互与视觉规范**:
  为避免与下方历史档案出现内容冗余和认知阻滞，今日层级的作业报告节点采用**“轻量级通知卡片”**形态。

```text
[节点标]     18:00
  🟣        ┌─[ 轻量级白底卡片 (包含大字触控区) ]────────────┐
  │         │  📄 今日作业与学情归档已完成                     │
  │         │  李老师已完成对孩子今日学习情况的诊断，上传了错题抓  │
  │         │  拍，并附上了带班寄语。                          │
  │         │  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │
  │         │               👇 点击查看今日详细成长档案        │
  │         └───────────────────────────────────────────────┘
  │
[节点标]     16:50
  🟢        🏫 已安全入班
  │         确认进入托管教室
  │
[节点标]     16:30
  🟢        🟢 李老师已接 (校门口)
```

* **核心联动交互 (锚点平滑滚动)**:
  * **热区触发**: 整个 `18:00` 白底作业卡片为一整块可点击热区。
  * **丝滑降落**: 家长点击该卡片后，系统捕捉事件并调用原生 `scrollIntoView(smooth)` 行为，驱使页面平滑下滚。
  * **精准定位与高亮**: 视图精准降落在下方的“历史成长档案”里**今日 (例如 2月21日)** 的那张包含了五层架构图文所有细节的重度内容卡片上。落地瞬间，目标卡片会触发 `1.02` 倍微距放大及短暂发光阴影以提示家长的视觉焦点。

* **设置菜单 (Action Sheet)**:
  * 📞 联系老师
  * ❌ 退出登录
  * 取消

#### **US-L03: 登录业务逻辑**

* **老师登录流程**:

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 点击"我是老师" | 唤起微信原生手机号授权 |
| 2a | 手机号**已注册** | Toast"欢迎回来，XX老师" -> 跳转老师首页 |
| 2b | 手机号**未注册** | 弹出选择页：【新建机构】或【输入邀请码加入已有机构】 |
| 3a | 选择【新建机构】 | 创建机构并设为 admin -> 弹窗"🎉 账号创建成功" -> 跳转首页 |
| 3b | 选择【输入邀请码】| 校验通过后设为 staff -> 绑定机构 -> 弹窗"🎉 成功加入机构" -> 跳转首页 |

* **家长登录流程**:

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 点击"我是家长" | 唤起微信原生手机号授权 |
| 2a | 手机号**匹配学生档案** | Toast"欢迎回来，XX家长" -> 跳转今日动态页 |
| 2b | 手机号**未匹配** | 弹窗"😔 未找到学生档案" + 引导联系老师 |

* **验收标准**:
  * **场景1: 老板新建机构**
    * GIVEN 老师首次打开小程序并授权手机号
    * WHEN 默认创建机构（或选择创建）
    * THEN 系统自动建立 `teachers` (role=admin) 和 `org_settings` (含随机邀请码)
  * **场景2: 员工凭码加入**
    * GIVEN 员工授权新手机号后，选择输入已知的6位邀请码
    * WHEN 验证通过
    * THEN 系统创建 `teachers` (role=staff) 关联该机构，共享所有学生/班级数据
  * **场景3: 家长匹配失败**
    * GIVEN 家长手机号未被任何老师录入
    * WHEN 点击"我是家长"并授权手机号
    * THEN 弹窗提示"未找到学生档案"，引导联系老师
