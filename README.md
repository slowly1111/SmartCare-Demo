# SmartCare 智能托管助手 (MVP v1.0 Demo)

这是一个基于 HTML/CSS/JS 的纯前端交互演示项目，展示了 **SmartCare 智能托管助手** 的核心功能流程。

## 📱 演示入口

🚀 **[点击这里体验 Demo](index.html)**  
*(部署后直接访问项目根域名即可，例如 `https://smart-care-demo.vercel.app/`)*

## ✨ 核心功能

### 👨‍🏫 老师端
*   **首页**: 班级概览与统计
*   **考勤工作台**: 两段式考勤（校门接送 -> 班级入托）、极速点名
*   **连拍相机**: 作业极速归档、双通道入口 ("今日全对" / "提交错题")
*   **学生档案**: 个人成长记录、一键联系家长

### 👨‍👩‍👧 家长端
*   **今日动态**: 查看孩子接送状态、作业报告
*   **历史档案**: 查看历史错题集与老师评价



## ⚠️ 注意事项
*   本 Demo 为 **纯前端演示**，数据均为本地 Mock 数据，刷新页面后会重置。
*   并没有连接真实的后端数据库。

## 📝 版本更新日志 (Changelog)

### v1.0.9 (2026-02-22)
*   **作业录入功能升级**：极简录入与“操作即保存”的无感体验，支持跨校、跨班级隔离数据。
*   **账号体系升级**：重构一键授权登录，新增“校长新建机构、生成邀请码并邀请老师加入”的协作模式。
*   **其他核心体验升级**：
    *   **学情报告属性升级**：原本单一的“错题集”全面升级为包含考勤、作业明细、错图和评价寄语的《今日学情诊断报告》。
    *   **极速连拍与错题反馈**：新增相机双通道入口（“今日全对”捷径 / 常规照片连拍）；连拍的照片将**首选作为“草稿”暂存**，支持老师利用碎片时间统一补充作业情况和评价反馈，避免了必须“拍一组评一组”的打断感。
    *   **考勤与防误触互通**：新增左滑手势呼出撤销/请假，并实现高优先级交互的防抖隔离。
    *   **双端档案展示层级升级**：家长端与老师端的历史档案呈现，由原本的粗颗粒度列表，升级为涵盖「考勤动态、作业完成明细、表现评价标签、错图大图预览、老师附加寄语」的**五层沉浸式结构卡片**。
