# SmartCare 智能托管助手 (MVP v1.0 Demo)

这是一个基于 HTML/CSS/JS 的纯前端交互演示项目，展示了 **SmartCare 智能托管助手** 的核心功能流程。

## 📱 演示入口

🚀 **[点击这里体验 Demo](demo-nav.html)**  
*(部署后请访问 `/demo-nav.html` 或设置其为默认首页)*

## ✨ 核心功能

### 👨‍🏫 老师端
*   **首页**: 班级概览与统计
*   **考勤工作台**: 两段式考勤（校门接送 -> 班级入托）、极速点名
*   **连拍相机**: 作业极速归档、双通道入口 ("今日全对" / "提交错题")
*   **学生档案**: 个人成长记录、一键联系家长

### 👨‍👩‍👧 家长端
*   **今日动态**: 查看孩子接送状态、作业报告
*   **历史档案**: 查看历史错题集与老师评价

## 🛠️ 部署指南 (Vercel)

本项目是纯静态页面，非常适合部署在 Vercel。

1.  将本项目 Fork 或 Clone 到你的 GitHub。
2.  登录 [Vercel](https://vercel.com)。
3.  点击 **"Add New"** -> **"Project"**。
4.  选择 **`SmartCare-Demo`** 仓库并导入。
5.  点击 **"Deploy"**。
6.  部署完成后，分享生成的链接即可体验。

> 💡 **提示**: 建议在 Vercel 的 Settings -> Git -> ROOT DIRECTORY 保持默认 (`./`)。

## ⚠️ 注意事项
